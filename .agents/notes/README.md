# Session notes (memory)

This directory contains learnings from previous agent sessions. Read
relevant notes before starting work; they capture gotchas, decisions,
and non-obvious project knowledge that is not in the code or AGENTS.md.

## Convention

Record a learning as a file named:

```
<date>-<learning-short-description>.md    # e.g. 2026-08-22-payload-v6-codec.md
```

Keep notes short and current. Delete or update notes that become stale.
